# FlyRank Capstone — Embeddable Widget & Lead-Capture Platform

A backend platform that allows customers to create embeddable website widgets and safely collect visitor submissions through a public API.

## Status

Currently in Phase 1 — Design.

## Planned Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker Compose
- Vanilla JavaScript
